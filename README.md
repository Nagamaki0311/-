# 人生年表メーカー

名前と人生の節目を入力し、出来事・コメント・気分の折れ線を一枚の年表にする静的Webアプリです。PCは編集とプレビューの2列、スマホは切り替えて利用できます。外部パッケージは使用しません。

## 機能

- 年齢・学年・転機のガイド。0〜120歳、最大100件。学校の各学年と社会人の開始年齢に対応します。
- 各節目に時期、出来事、コメント、0〜10のスコアを記録。詳細設定で−10〜−1も使えます。
- 年表の見出しは「○○の人生年表」。名前が空なら「わたしの人生年表」です。自由タイトルの入力欄はありません。
- 個別選択・全選択・選択した節目の一括削除・全削除。削除前に件数を確認し、削除後は一度の操作で元の順序に戻せます。
- PNG／SVG一枚保存、再編集用JSON、対応ブラウザでMP4またはWebM、対応端末で画像共有。

## 多数の節目の配置

節目を横幅1600pxの一本の軸へ詰め込む方式を廃止しました。各段は最大9件とし、段数・文字量・カード幅・横長16:10／正方形1:1／縦長約2:3の比率を合わせて盤面寸法を決めます。多い場合も一枚の画像内で時系列に折り返します。

各段に年齢の範囲と共通のスコア尺度を表示します。その段の点は実際の年齢間隔に対応します。次の段へ移る箇所は案内矢印で区別し、年齢軸の連続性や縮尺を偽装する折れ線は引きません。年齢間に大きな空白がある場合も段を分けて密集を避けます。同年齢の記録は点の年齢座標を保ち、出来事カードは別々に表示します。同じ年齢・スコアの点には「同時期○件」を表示します。

文字は省略せず折り返し、長文は盤面を広げます。画面では縦横スクロール・倍率変更・全体表示を利用できます。PNGは最大8192px／1600万画素に収めて縮小し、縮小時は画面に明示します。大量の長文を拡大して読む場合はSVGをご利用ください。

## 動画

画像の全体表示とは別の見せ方です。左端の最初の点から始まり、カメラが年齢順に折れ線の上下を追います。各節目に到達すると、その出来事・コメントを表示し、読みやすい大きさで停止します。短いカードは中央に配置し、長いコメントは下へ移動して最後まで表示します。段をまたぐ際は次の段へ移動します。

動画の長さは節目数とコメント量から計算し、作成前に表示します。最後に約1.4秒の停止時間があります。画像やコメントを毎フレーム作り直さず、背景と各カードを一度だけ画像化して再利用します。合計画像メモリの見積もりが上限を超える年表は、生成前にエラーとPNG／SVG保存の案内を表示します。記録は変更しません。

`MediaRecorder` と `canvas.captureStream` が必要です。MP4対応時はMP4を優先し、非対応ならWebMを使用します。実際の形式は作成画面に表示します。音声・GIF出力には対応していません。

## 起動と検証

Python 3で起動できます。ビルドや依存パッケージのインストールは不要です。

```sh
python3 dev-server.py
# http://localhost:3000
```

Node.js 22以降では以下も利用できます。

```sh
npm run dev
npm test
npm run check
```

開発サーバーは `--port 4173 --host 127.0.0.1 --strictPort` に対応します。ES Modulesを利用するため、HTMLを直接開かずHTTPで配信してください。

## 保存とプライバシー

下書きはブラウザのlocalStorageに自動保存します。入力データのアップロード、通信API、アクセス解析、外部フォントはありません。画像・動画も端末内で生成します。CSPは `connect-src 'none'` です。共有ボタンを押した場合だけOSの共有シートへ画像を渡し、投稿先と送信は利用者が選びます。非対応の場合はPNGを保存して手動で添付できます。

ブラウザの保存データ削除やプライベートモード終了で下書きが失われることがあります。大切な記録はJSONでも保存してください。サンプルは下書きと別データで、表示中のサンプルを書き出す場合は明示します。

JSONはバージョン1、250KBまで。値域・文字数・ID・不正な制御文字を検証してから読込み確認を表示します。以前の自由タイトルはバックアップの互換性のため保持しますが、表示や画像・動画には使用しません。以前の下書きはそのまま読み込めます。

## 公開

GitHub Pagesを使用する場合はmainへの反映後、Settings → Pages → Deploy from a branch → main / (root)を設定します。相対パスのため `/-/` 配下でも動作します。Sitesの公開設定は配信用チェックアウトで管理しています。

## 検証の範囲

`tests/model.test.js` に保存形式、入力境界、ガイド、段組み、年齢軸、吹き出しと線の非交差、一括削除と復元、見出し、カメラ移動・段階表示・長文パン・メモリ上限を検証するテストがあります。`cameraFrameSvg` は実動画と同じカメラ計算・表示対象を使う描画確認用APIです。

管理プレビュー基盤に制限があり、実ブラウザでのPNG保存・動画のエンコード／再生・スマホ操作は未検証です。構文確認、モデル／描画処理のテスト、SVGの実描画とカメラキーフレームの確認とは区別します。
