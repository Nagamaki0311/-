# 人生、山あり谷あり。 — 人生年表メーカー

時期・できごと・コメント・人生の調子を、ひとつにつながった人生ボードにする静的Webアプリです。日本のバラエティ番組の年表をイメージした、カラフルな吹き出し・番号スタンプと紙のようなデザイン。PCは入力とプレビューの2列、スマホはタブ切り替えで使えます。

## できること

- 転機・年齢・学年の3つの作成ガイド。小学校〜大学、社会人の開始年齢にも対応。追加時は既存の記録を保持します。
- 0〜120歳、最大100件の節目。できごと・コメント・0〜10の調子を入力。詳細設定で−10〜−1を解放できます。
- 年齢の間隔に沿った折れ線と、その点に直接つながる思い出の吹き出し。全節目の時期・できごと・コメントを一枚で表示します。同じ年齢の複数イベント、削除の取り消し、時系列再生にも対応。吹き出し・点はキーボードでも選べます。
- PNG / SVG画像、再編集用JSON、MP4またはWebM動画の保存。対応端末ではPNGをOSの共有画面へ渡せます。
- 横長・正方形・縦長のボード配置。吹き出しが重ならないように上下のレーンへ配置し、全文を残して一括保存します。画面では縦横スクロール・拡大縮小・全体表示を選べます。

## 起動と検証

アプリ自体にはビルドもパッケージのインストールも必要ありません。Python 3で静的配信できます。

```sh
python3 dev-server.py
# http://localhost:3000
```

Node.js 22以降がある場合は、次のコマンドでも操作できます。`npm install` は不要です。

```sh
npm run dev
npm test
npm run check
```

`dev-server.py` は `--port 4173 --host 127.0.0.1 --strictPort` の形式にも対応します。ES Modulesを使うため、`index.html` を直接開かずHTTPで配信してください。

## 保存とプライバシー

入力内容はこのブラウザの `localStorage` にのみ自動保存します。通信API、外部フォント、解析、データアップロードはありません。CSPでも `connect-src 'none'` を指定しています。サンプルは自分の下書きとは別データです。サンプル表示中にJSONを保存すると、ボタンの表記どおりサンプルを書き出します。自分の年表に切り替えたあとは自分の記録を書き出します。

ブラウザのデータ削除、別端末への移動、プライベートモード終了で下書きが失われることがあります。大切な記録は「編集データを保存」からJSONでもバックアップしてください。JSONの読み込みは検証後に確認画面を出し、現在の内容を置き換えます。不正なファイルでは下書きを変更しません。

画像・動画の生成も端末内で行います。シェアボタンだけがOSの共有画面を開き、実際の投稿先・送信は利用者が選びます。Web Share APIはHTTPSと対応ブラウザが必要です。非対応の端末では保存した画像を手動で添付できます。

## 出力の仕様と制限

- PNG / SVGは全節目・全コメントを含む一枚の人生ボードです。ページ分割しません。レイアウトの種類で基準幅・グラフの高さ・吹き出し幅が変わり、節目や文章が多い場合はボードを広げます。固定の縦横比ではありません。
- PNGは端末のメモリを守るため、最大辺8192px・1600万画素以内へ必要に応じて全体を縮小します。縮小する場合は保存画面に表示します。長大な年表や全文の拡大閲覧には、元の文字と配置を保つSVGがおすすめです。
- 動画は画像と同じ人生ボードを背景に使い、折れ線が時系列に沿って伸びる音声なしのアニメーションです。節目の数に応じて8秒〜約3分、最後に約1.2秒停止します。全文を載せたボードを全体表示するため、節目が多い動画では文字が小さくなります。拡大して読む用途にはSVGをご利用ください。動画は背景を一度だけ画像化し、毎フレームのSVG解析は行いません。
- `MediaRecorder` と `canvas.captureStream` に対応するブラウザで動画を作れます。MP4を優先し、非対応ならWebMを使います。実際の対応状況は画面に表示します。GIF出力はありません。
- 文字表示には端末にある日本語フォントを使用します。環境によって字形や絵文字の見え方は変わります。
- データ形式はバージョン1。読み込みは250KBまでで、値域・文字数・重複ID・不正な制御文字などを検証します。

## 構成

- `index.html` / `styles.css`: 画面とレスポンシブデザイン
- `app.js`: 入力、端末保存、プレビュー、共有、ダイアログ
- `model.js`: データ検証、ガイド、年齢に沿った座標と吹き出しレーンの計算
- `export.js`: 画面・SVG・PNG・動画で共通の人生ボード描画
- `tests/model.test.js`: 保存形式、入力境界、ガイド、グラフ、出力の回帰テスト
- `docs/design.md`: デザイン仕様

元の開発用テンプレートの運用文書は保持しています。このリポジトリにアプリを作成する、という利用者の指定に従って実装しています。
