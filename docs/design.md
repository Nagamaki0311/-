# 人生年表メーカー：デザイン仕様

## 目的と利用場面

自分の人生を思い出しながら、出来事と言葉、気分の上下を一枚の年表にする。初めて使う人がスマホでも迷わず入力でき、保存画像はSNSでも内容が伝わることを優先する。データは端末内に保持し、共有は利用者の操作で行う。

## 方向性の比較

| 候補 | 表現 | 判断 |
| --- | --- | --- |
| バラエティ番組の人生グラフ | 生成りの背景、濃紺の太字・罫線、黄色の見出し、赤い折れ線 | 採用。イベントと感情の上下が主役になり、親しみと視認性を両立できる |
| 思い出アルバム | 紙の質感、手書き風文字、写真中心 | 温かいが、写真がなくても成立する本アプリでは入力とグラフの明瞭さを優先する |
| 株価ボード | 暗色背景、鮮やかな線、数字中心 | チャートは明瞭だが、初心者が人生を振り返る入口としては硬い |

## 採用する視覚表現

タイトルは「人生、山あり谷あり。」を中心とし、「人生年表メーカー」を用途の説明として添える。番組の見出しを思わせる太い文字と黄色の帯で楽しさを出し、装飾はタイトルとチャートに集中する。入力欄の背景は白、説明は簡潔にする。

- 背景：暖かい生成り。主要文字・罫線：濃紺。見出し：黄色。人生の折れ線：赤。
- 日本語は読みやすいゴシック体。見出しは太字、本文は十分な行間を確保する。フォントは端末内のものを使い、外部取得しない。
- 余白は8px単位を基本に、節目間は広く、同じ節目の入力群は近づける。
- カードと影を乱用せず、罫線、番号、見出しの強弱で構造を示す。
- 数値や上下の意味は色だけで示さず、値とラベルも併記する。

## レイアウトと操作

PCでは左に編集、右にライブプレビューを並べ、変更の結果がすぐ分かるようにする。スマホでは「編集」「プレビュー」を切り替え、片方の作業に集中できるようにする。主要操作は押しやすい大きさにし、画面幅による横はみ出しを防ぐ。

入力の入口は「年齢ごと」「学年ごと」「転機ごと」の3種とする。ガイドは候補の追加を助け、切替で既存データを消さない。各節目では年齢、任意ラベル、イベント、コメント、気分を編集できる。気分は通常0〜10、詳細設定で−10〜−1を解放し、設定を閉じても入力済み負値を保持する。

チャートの横軸は年齢、縦軸は気分とする。点とイベントは同じ順序・番号で対応し、点の選択から該当イベントを確認できる。同年齢の複数イベントも残す。削除後は元に戻せる導線を示す。

## 保存・共有

横長、正方形、縦長の出力を用意する。チャートに加え、全イベントとコメントを読みやすく配置し、件数が多い場合は画像の高さを伸ばすなどして文字の欠落を避ける。PNGは共有用、SVGは拡大用、JSONは再編集用として用途を短く示す。

時系列アニメーションは再生と停止を明示する。動画保存はブラウザが対応するMP4またはWebMを表示し、未対応形式を実装済みとして見せない。SNS共有は共有シートを利用し、未対応時は画像保存を案内する。

## 状態とアクセシビリティ

- 空状態ではガイドから始める操作を示す。サンプルと自分のデータは区別する。
- 自動保存の成功・失敗を伝える。保存できない場合はJSON保存で退避できるようにする。
- 不正な読込みファイルは理由を表示して拒否し、編集中のデータを保持する。
- すべての入力に可視ラベルを付ける。キーボードで全操作を行え、フォーカス位置を明瞭にする。
- 本文のコントラストは4.5:1以上、操作対象は原則44px以上とする。スマホ入力時に不必要な拡大が起きない文字サイズを使う。
- 操作結果は適切なライブ領域で通知する。エラーは色だけに依存しない。
- アニメーションは時系列理解と操作結果の提示に限定する。`prefers-reduced-motion`を尊重し、自動再生しない。

## 画面確認

PC幅と390px幅で編集・プレビュー・保存を確認する。長文、負値、同年齢、空状態、多数のイベント、不正JSON、保存失敗を確認し、画像で文字が読めることと内容が欠けないことを検証する。
