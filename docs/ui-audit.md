# UI・文言の監査 — 2026-11-18

「AI生成らしさ」は客観的な属性として判定せず、HTML/CSSと既定表示の具体的な重複・余白・文字階層・表現を確認した。

| 確認対象 | 問題 | 反映した整理 |
|---|---|---|
| ヘルプ | 「使い方」のテキストと矢印が常時幅を取る | 円内の疑問符へ変更。可視円28px、押下領域44px。aria-label/title/関連ダイアログを維持 |
| 保存状態 | ヘッダーと編集欄で端末保存を重複説明 | 編集欄の自動保存状態に集約。詳しい説明はヘルプへ |
| プレビュー | 見出し、寸法、サンプル表示、再生説明が積み重なる | 件数/寸法とサンプル表示をツールバーへ。自明な補足と余分な見出しを削減 |
| 画像設定 | 16:10/正方形/縦長の比率選択がパノラマと矛盾 | 画像設定から撤去。動画の画面比率として動画ダイアログ内に明示 |
| 書体と太さ | 文字サイズ/太さの種類が多く、階層が不揃い | 日本語ゴシックの端末内フォントを優先。本文14px、ラベル12px、補足11px、見出し14/18px。本文400、操作600〜700を基本にし、スマホ入力は16px |
| 余白 | 同じ役割の操作群で間隔が不揃い | 4/8/12/16/24pxの単位を採用。ヘッダー56px、本文上部16px、編集とプレビュー間24pxを基本に整理 |
| 文言 | 問いかけの繰り返し、詩的な定型句、入力指示の出力混入 | 未入力ラベルは簡潔にし、ガイドは機能を説明。サンプルを入学/就職/転職等の具体的な内容へ。出力に入力指示を入れない |
| 記号 | すべて記号化すると保存形式や削除対象が曖昧になる | 拡大縮小/再生/閉じる/全体表示は記号と代替名を使用。保存形式・一括削除・対象件数は文字を維持 |

年表は単一の左→右の年齢軸へ変更し、文字を無理に縮めず横幅を確保。縦軸は線形0〜10/負値時−10〜10を保ち、560pxの描画領域、太い折れ線、点のスコアと薄い面塗りで起伏を示す。

利用者が入力した出来事やコメントの文体は変更しない。既定UI・既定サンプルのみ整理した。実ブラウザの書体選択結果・PC/スマホ実画面・PNG保存・録画は既報の環境制限により未検証。コード確認およびSVGの実描画と区別する。
