# 設計判断

## D-001 このリポジトリをアプリとして初期化する

ユーザーが明示的に指定したリポジトリに実装する。テンプレートの「別リポジトリで実装」より今回のユーザー指定を優先する。既存のエージェント設定は保持する。

## D-002 外部依存なしの静的アプリ

HTML / CSS / JavaScriptとブラウザ標準APIで編集、SVGチャート、画像生成、対応ブラウザでの動画生成を行う。データ保存はlocalStorageとJSON。外部フォントや解析サービスを使わない。SNS投稿は利用者が共有シートで選択する。

## D-003 出力形式

PNG、SVG、編集用JSON、対応するMIMEを検出したMP4またはWebM。GIFは依存や独自エンコーダーを増やすため初版では扱わない。動画未対応のブラウザには静止画保存を案内する。

## D-004 GitHub連携で変更を反映

実行環境からのGit接続はプロキシ接続に失敗するが、GitHub連携は読み書き可能。既存ツリーを基点に追加・更新ファイルをコミットし、作業ブランチとPRを作る。mainを直接変更しない。
