# 人生年表メーカー：デザイン仕様

## 現在の目標と優先順位

わかりやすく、直感的で、見やすく、おもしろい年表を作る。利用者が入力した時期・出来事・全文コメント・スコア・折れ線を、同じ一枚の年表に表示する。2026-11-18の追加指定を優先し、段組み・時系列の折り返しと固定比率への最適化は廃止する。年表は左から右へ連続するパノラマとし、必要な横幅を確保する。

番組風の配色と番号札は残すが、サイト自体は編集作業のための道具として整える。大きなhero、英語のキャッチコピー、詩的な説明、意味のない飾りや余白は置かない。見出しは名前から「○○の人生年表」を生成し、未入力時は「わたしの人生年表」。自由タイトル欄は設けない。既存JSONのtitleは読み込み互換性のため保持しても表示には使わない。

## 実査した問題と調整方針

「AI生成らしさ」を客観的な属性として断定せず、現行HTML/CSS/文言の具体的な問題を直す。

| 対象 | 現行で確認した状態 | 調整 |
| --- | --- | --- |
| 文字の階層 | 10/11/12/13/14/18/19/20/22pxなど多くのサイズが混在 | 通常本文14px、入力14px（スマホ16px）、ラベル12px、補足11px、節見出し14〜15pxを基本にする。重要な数値以外で900の太さを乱用しない |
| 余白 | 13/17/18/20pxなどの間隔が混在し、同じ役割のまとまりが揃わない | 8/12/16/24pxを基準に、入力内8px・同じ操作群12px・操作群間16px・編集とプレビュー間24pxへ整理する |
| 保存状態 | headerの「端末内に保存」とeditorの自動保存状態が近接して重複 | 保存状態は一箇所に集約。プライバシーの詳細はヘルプに置く |
| ガイド | モードの小見出しと直下の説明で同じ内容を重ねている | モード名を残し、説明は追加する範囲・上限・注意など実際に必要な一文だけにする |
| プレビュー | 「プレビュー」見出し、件数/寸法、再生タイトルと説明が積み重なる | 件数と表示操作を同じツールバーにまとめ、再生はボタンと状態を中心にする。自明な補足は省く |
| 旧画像形式 | 横長16:10・正方形1:1・縦長約2:3と折り返し案内が残る | パノラマ画像の仕様と矛盾する比率選択・折り返し文言を撤去。動画の出力比率を別用途で残す場合は動画の設定内に明記する |
| 入力一覧の空状態 | 「どんなことがありましたか？」などの問いかけを各項目で繰り返す | 未入力の項目は「未入力」。入力欄のplaceholderは具体例か「コメントを入力」程度にする |
| 保存の説明 | 「すべての思い出」「くっきり」「おすすめ」などの表現が混ざる | 件数・画像寸法・PNG縮小の有無・SVGでは原寸を保持することを簡潔に伝える |

書体は外部通信を使わず、日本語のゴシック体を優先する。例：Hiragino Sans、Hiragino Kaku Gothic ProN、Yu Gothic、Meiryo、system-ui。本文は400、操作・ラベルは600〜700を基本とし、本文の行間は1.5〜1.65に統一する。セリフ体、詰めた字間、長い文章への過度な太字は使わない。

## 記号化と操作の明瞭さ

ヘルプは丸の中に「?」を入れたマークにする。可視円は約28pxでも、押せる範囲は44×44px以上とする。ボタンには「使い方」のアクセシブル名とtitle、help-dialogへの関連を残す。キーボードフォーカスを明瞭にする。

既に意味が明瞭な「＋」「−」「↺」「×」は使う。全体表示を四隅の枠のSVGアイコンにする場合も、titleとaria-labelで「全体表示」を示す。アイコン化を目的に、削除の対象件数・削除する操作・PNG/SVG/JSONの違いを消さない。危険な操作や形式の選択には短い文言を残す。星や矢印を操作と無関係なボタン装飾として増やさない。

## 節目数とガイド

通常の節目追加は30件までとする。「年齢ごと」のガイドだけは例外として30件を超えて追加できる。年齢0〜120歳のガイドを扱う場合、最大121件になる。既存の100件までのJSONや下書きを切り捨てず読み込めるようにし、通常操作による追加上限と保存データの読み込み上限を混同しない。

年齢ガイドの選択時には短い注意を表示する。文言例：「年齢ごとは30件を超えて追加できます。件数が多いと表示・出力が崩れる場合があります。」上限超過を黙って無視したり、成功したように表示したりしない。30件を超える既存データも削除・編集・バックアップできる状態を保つ。

## 左から右へ続くパノラマ年表

一本の時系列と一つのスコア尺度を使い、途中で次段へ折り返さない。画像の横幅はイベント数、文字量、年齢の間隔から求める。画面の枠内へ収めるために文字や点の間隔を極端に縮小しない。

- 横軸は実際の年齢の間隔を保持する。必要な点間隔と吹き出しの幅から横幅を増やす。等間隔の節目順を年齢の等間隔に見せかけない。
- 全節目の文章を同時に表示し、点に近い上下の吹き出しへ直接つなぐ。吹き出し間・番号札・スコア札・線の衝突を検証する。単純なケースは短い接続線にし、遠いガターへ回す経路を常用しない。
- 同年齢の複数イベントは別番号と別カードで保持し、点が同じ場合は件数等で明示する。配置の都合で時刻が違うように表示しない。
- 全文コメントを省略しない。長文ではカードを縦に伸ばしても、年表の時間方向は横に保つ。空の出来事を指導用の文章で埋めない。
- スマホもPCも、盤面だけを横に動かせるようにする。サイト本体の横はみ出しを防ぐ。読みやすい倍率と全体表示を用意し、全体表示で文字が小さくなることを通常の閲覧倍率と混同しない。

## 起伏と落差の見せ方

スコアの意味を変えずに、グラフの縦の描画領域を十分に確保する。通常は0〜10、負値があれば−10〜10を明示し、入力値に合わせて縦軸を勝手に切り詰めない。軸を省略して差を誇張しない。

折れ線は背景と十分な差があるコーラル系の色で太く描き、点とスコアを判読できるようにする。少量の面塗りで高さの変化を補助してもよい。滑らかな補間で実データにない極値を作らず、節目の上昇・下降・大きな落差を折れ線の形として見せる。色だけで良し悪しを伝えず、値と位置を併記する。

背景は生成り、主要文字は濃紺、カードは黄色・ミント・水色・淡いコーラルを使い分ける。カード色を気分の良し悪しと混同しない。楽しさは配色・番号・入力内容とグラフの変化から出し、キャッチコピーを増やさない。

## 画像・動画・保存

画面、SVG、PNG、動画の元データとパノラマ配置を共有する。全節目を一枚で保存し、ページ分割や別紙一覧を作らない。パノラマでは画像が非常に横長になることを明示し、PNGの画素上限で縮小される場合は事前に寸法と縮小を表示する。SVGは全内容をベクターのまま保持する。PNGの縮小を黙って切り捨てやクロップに変えない。

動画は左端から右へ折れ線の上下を追い、到達後に対応する出来事・コメントへ寄って読む時間を置く。折り返し段への移動処理は不要になる。短いカードは中央、長文は最後までパンする。動画の形式・所要時間・メモリ上限の案内は実際の処理と一致させる。

既存の一括選択・一括削除・件数確認・取り消し・JSON読込み確認・端末内保存・保存失敗時の通知は維持する。サンプルと本人の下書きを混同しない。

## 検証

6件、学年ガイド27件、通常上限30件、30件超の追加拒否、年齢ガイド31/121件、同年齢集中、長文・幅広英字・絵文字・負値・空状態を確認する。全ケースで一段の連続時系列であること、文章・点・線・札が対応し全文を保持することを検証する。

HTML/CSS/文言では、丸?の押下面・アクセシブル名、短い機能説明、同じ役割の余白と文字サイズ、旧比率/折り返し文言の残存、AIという一般的な印象ではなく実際の重複や不整合が解消したかを確認する。PCと390pxの実ブラウザ確認ができない場合は、その範囲を未検証と明記する。動画は冒頭・途中・最後・長文のカメラフレームと実録画を区別して確認する。
